# «Άκου… Βλέπε… Σώπα» — Το Βιβλίο (Επίσημη Ιστοσελίδα)

Μια σύγχρονη, ατμοσφαιρική ιστοσελίδα παρουσίασης του ψυχολογικού θρίλερ και υπαρξιακού δράματος **«Άκου… Βλέπε… Σώπα»**.

## 📖 Σχετικά με το Έργο
- **Τίτλος:** «Άκου… Βλέπε… Σώπα»
- **Σελίδες:** 196 (Πλήρες Χειρόγραφο)
- **Είδος:** Ψυχολογικό Θρίλερ / Υπαρξιακό Δράμα
- **Χώρος Δράσης:** Γενικό Νοσοκομείο Πειραιά (Δωμάτιο 312), Παραλιακή Λεωφόρος Αθηνών, Ιερός Ναός

> *«Και ίσως τελικά αυτό να είναι η αγάπη. Όχι να βρίσκεις κάποιον αψεγάδιαστο, αλλά κάποιον που, αφού δει όλα τα σκοτάδια σου, εξακολουθεί να σου πιάνει το χέρι και να σου ψιθυρίζει: “Γύρνα πίσω… δεν τελείωσε ακόμη”.»*

## ✨ Κύρια Χαρακτηριστικά Ιστοσελίδας
1. **Κινηματογραφική Παρουσίαση Hero:** 3D εξώφυλλο, ατμοσφαιρικός σχεδιασμός νουάρ και εξομοιωτής ηλεκτροκαρδιογραφήματος (Δωμάτιο 312).
2. **Ηχητική Ατμόσφαιρα (Web Audio API):** Ενσωματωμένος procedural ρυθμικός παλμός μόνιτορ (72 BPM) χωρίς εξωτερικά αρχεία ήχου.
3. **Ανάλυση 3 Κεφαλαίων:** Διαδραστική περιήγηση στα κεφάλαια *ΑΚΟΥ*, *ΒΛΕΠΕ*, και *ΣΩΠΑ* με αποκλειστικά εικαστικά.
4. **Ψυχογραφικά Προφίλ Χαρακτήρων:** Αναλυτικά πορτρέτα για τους Ορφέα, Φαίδρα, Μάνο, Στέφανο, Ιόλη & Αλέξη, Σωκράτη.
5. **Πίνακας Εγκληματολογικών Στοιχείων:** Detective board με τα κομβικά πειστήρια (μαύροι φάκελοι, κομμένα φρένα στα 130 km/h, βίντεο-ντοκουμέντο).
6. **Αναγνωστήριο Αποσπασμάτων:** Επιλεγμένα κείμενα με ρύθμιση μεγέθους γραμματοσειράς και επιλογή serif/sans.
7. **Φιλοσοφικό Δίλημμα («Άραγε Συμφωνείτε;»):** Διαδραστική ψηφοφορία σε πραγματικό χρόνο και δυνατότητα καταχώρισης σκέψεων αναγνωστών (με αποθήκευση στο LocalStorage).
8. **Πλήρης Προβολή & Λήψη PDF:** Ενσωματωμένος αναγνώστης του πλήρους PDF (196 σελίδες, 1.5MB) και άμεση λήψη.

## 🛠️ Τεχνολογικό Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Custom Dark Noir Palette & Glassmorphism
- **Icons:** Lucide React
- **Audio:** Web Audio API (Synthesized Real-Time Heartbeat & Ambience)
- **Deployment:** Vercel (Edge CDN)
